# Image Worker

Serve diagrams as SVG and PNG images from a Cloudflare Worker, for Markdown hosts such as GitHub.

The Worker at `https://ondine.sh` reads the Mermaid source from the request and compiles it with the module for every diagram type. The Worker is part of the documentation site in `site/`. The build precompiles its compiler module, so a request downloads nothing. The [GitHub Images](/docs/guides/github) guide shows common tasks.

```md title="README.md"
<!-- Renders a two-node flowchart in the light scheme -->

![Flow](https://ondine.sh/eJxLy8kvT85ILCpR8AniUlBwVNDVtVNwAgBUvQYu.svg)
```

## Request

```txt
GET /<payload>.svg?scheme=light|dark|auto
GET /svg?source=<source>&scheme=light|dark|auto
GET /<payload>.png?size=full&scheme=light|dark
GET /png?source=<source>&size=full&scheme=light|dark
```

The Worker also accepts `HEAD`. Other methods return `405` with an `allow: GET, HEAD` header. Other paths return `404`.

### payload

- **Type:** base64url string

The Mermaid source as UTF-8, compressed with zlib deflate, then encoded as base64url without padding.

```ts
import * as Zlib from 'node:zlib'

// Encodes a diagram for the request path
const payload = Zlib.deflateSync('flowchart LR\n  A --> B').toString('base64url')
```

### source

- **Type:** percent-encoded string

The Mermaid source in the query of `/svg` or `/png`. Authors and agents that cannot compress the source use this form. A URL with `source` grows faster than a URL with a payload.

```md
<!-- Renders a two-node flowchart from plain source -->

![Flow](https://ondine.sh/svg?source=flowchart%20LR%0A%20%20A%20--%3E%20B)
```

### scheme

- **Type:** `'light' | 'dark'{:ts}`

Selects the color scheme of an SVG image. The default is `light`. The `auto` value follows `prefers-color-scheme`.

A full-size PNG also accepts `dark`. Cards always draw the light scheme.

```html
<!-- Shows the dark variant when GitHub uses a dark theme -->
<picture>
  <source
    media="(prefers-color-scheme: dark)"
    srcset="https://ondine.sh/<payload>.svg?scheme=dark"
  />
  <img alt="Flow" src="https://ondine.sh/<payload>.svg?scheme=light" />
</picture>
```

### size

- **Type:** `'full'{:ts}`

Draws a PNG at the diagram's own size instead of on a card. The image has two pixels per SVG unit and a background in the scheme's color. Diagrams over 8 megapixels at that density scale down to fit.

```md
<!-- Shows a wide diagram at full resolution on hosts that do not display SVG images -->

![Flow](https://ondine.sh/<payload>.png?size=full)
```

## Response

### PNG Cards

The `.png` and `/png` forms draw the diagram on a 1200x630 card in the light scheme. This size fits link previews. If a link previewer such as Slackbot requests an SVG address, it receives an HTML page whose `og:image` is the card.

```md
<!-- Shows the diagram on hosts that do not display SVG images -->

![Flow](https://ondine.sh/png?source=flowchart%20LR%0A%20%20A%20--%3E%20B)
```

### Full-Size PNG

The `size=full` form returns the diagram alone as `image/png`, with the same cache headers as a card.

### Success

The Worker returns status `200` with the compiled SVG. A `<style>` element after the root tag sets `--ondine-bg`, `--ondine-fg`, and `--ondine-line` for the scheme, because images cannot inherit page styles.

| Header                    | Value                                                  |
| ------------------------- | ------------------------------------------------------ |
| `cache-control`           | `public, max-age=86400, stale-while-revalidate=604800` |
| `content-security-policy` | `default-src 'none'; style-src 'unsafe-inline'`        |
| `content-type`            | `image/svg+xml; charset=utf-8`                         |
| `vary`                    | `User-Agent`                                           |
| `x-content-type-options`  | `nosniff`                                              |

A PNG card has the content type `image/png` and no `vary` header.

### Errors

The Worker returns status `400` with a card that shows "Ondine could not render this diagram." and then the error message. Caches keep this response for 300 seconds. A PNG request receives the card as a PNG.

| Cause                               | Message                                  |
| ----------------------------------- | ---------------------------------------- |
| Path or query over 4,096 characters | `Payload exceeds 4096 characters.`       |
| `/svg` or `/png` without `source`   | `The source query parameter is missing.` |
| Invalid base64url                   | `Payload is not base64url.`              |
| Invalid zlib data or UTF-8          | `Payload is not zlib-deflated UTF-8.`    |
| Source over 64 KiB after inflating  | `Source exceeds 65536 bytes.`            |
| Invalid Mermaid                     | The `RenderError` message                |

## Deploy

```sh
# Builds the site, including the image route, and deploys it with Wrangler

```
